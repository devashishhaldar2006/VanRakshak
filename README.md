# VanRakshak

VanRakshak is a React-based environmental protection dashboard for presenting forest and wildlife monitoring information in an accessible, visual interface.

## Highlights

- Modern Vite and React frontend
- Responsive dashboard views and data visualizations
- Motion and icon components for a polished user experience
- AI-assisted features powered by the Google GenAI SDK

## Development

```bash
cd frontend
npm install
npm run dev
```

The development server runs on port `3000`. Use `npm run build` to create a production build and `npm run lint` to run the TypeScript checks.
